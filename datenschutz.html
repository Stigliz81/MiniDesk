2. Webseite und Downloads

Die Webseite wird über GitHub Pages bereitgestellt unter https://stigliz81.github.io/MiniDesk/. Die Seite verwendet lokale HTML-/CSS-Dateien, eigene Bilddateien und direkte Downloads: keine eigenen Tracker, Analytics-Skripte, eingebetteten externen Fonts oder Kontaktformulare. GitHub kann beim tatsächlichen Hosting Verbindungs- und Protokolldaten einschließlich IP-Adresse verarbeiten. Eine nicht bestätigte feste Speicherfrist wird hier nicht angegeben.

GitHub Pages dient der Websiteauslieferung; Programm- und Quellenpaket werden als GitHub Release Assets bereitgestellt. Der Aufruf übermittelt notwendige IP-/HTTP-Daten an GitHub und Auslieferungshosts. Details und Rechte stehen unten sowie in den verlinkten GitHub-Datenschutzhinweisen.

3. Lokale Anwendung

Einstellungen, ausgewählte Wetterorte und Freigaben, Fensterpositionen sowie technische Logs liegen lokal im MiniDesk-Profil. Das Programm hat keinen eigenen Telemetrie- oder zentralen Profiluploadpfad. Lokale Logs sind nicht mit vollständiger Anonymität gleichzusetzen. Der bewusste Reset entfernt bekannte eigene Konfigurations-/Cachedateien und bietet eine externe Sicherung; Logs, fremde Dateien und bereits erzeugte Verknüpfungen können erhalten bleiben. Sicherungen können persönliche Pfade und Orte enthalten.

4. Wetter und Orte

Freiwillig freigegebene Vorhersagen verwenden Open-Meteo oder MET Norway. Die Anbieter erhalten IP-Adresse und angefragte Ortskoordinaten; MET erhält zusätzlich die eingetragene Kontaktkennung. Die optionale Ortssuche sendet Suchtext und IP-Adresse an Open-Meteo; Ortsdaten basieren auf GeoNames. Keine automatische Geräteortung. Radar verwendet RainViewer und OpenStreetMap, Satellitenbilder EUMETSAT/EUMETView oder MET Norway. Diese Dienste erhalten IP-/Verbindungsdaten und die angefragte Kartenregion beziehungsweise Bildreferenz. Freigaben sind getrennt; Widerruf stoppt Folgeabrufe, kann bereits an Anbieter übermittelte Daten nicht zurückholen. Caches liegen lokal.

5. Netzwerkdiagnose und Geschwindigkeit

Das sichtbare Network Detective führt regelmäßige ICMP-/DNS-/Routen- und gegebenenfalls TCP-Prüfungen aus. Vorhandene Internetziele sind 1.1.1.1 und 8.8.8.8; lokale DNS-/Routerinformationen werden für die Diagnose verwendet. Die Gegenstellen sehen Verbindungsdaten. Der native, bewusst gestartete Downloadtest ruft WOBCOM-/Hetzner-Testdateien ab und kann mehrere hundert MB bis über 1 GB Gesamtverkehr erzeugen. Ein externer M-Lab-Browserlink ist eine eigene Aktion; dessen Messstart und Datenschutz liegen auf der Anbieterseite. Integrierter M-Lab-Livebetrieb bleibt gesperrt.

6. Updateprüfung und Windowsfunktionen

Die MiniDesk-Versionsprüfung ruft nur nach Klick die konfigurierte HTTPS-version.json bei GitHub Pages ab, ohne Profil-/Geräteparameter. Der Host sieht IP-/Verbindungsdaten. Keine Hintergrundprüfung, automatische Installation oder ungefragte Programmpaketübertragung. WinGet und Windows Update kommunizieren separat mit den von Windows beziehungsweise Paketen konfigurierten Quellen; deren Lizenz-, Konto- und Datenschutzhinweise bleiben zuständig. Standardbrowserlinks öffnen nur nach Benutzeraktion.

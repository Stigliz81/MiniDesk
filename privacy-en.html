3. Local application

Settings, chosen weather locations and permissions, window positions and technical logs are stored locally in the MiniDesk profile. There is no application telemetry or central profile-upload path. Local logs do not guarantee anonymity. The deliberate reset removes known application configuration/cache files and offers an external backup; logs, unrelated files and created shortcuts may remain. Backups can contain personal paths and locations.

4. Weather and locations

Voluntarily enabled forecasts use Open-Meteo or MET Norway. Providers receive the IP address and requested coordinates; MET also receives the entered contact identification. Optional place search sends search text and IP address to Open-Meteo; location data is based on GeoNames. No automatic device geolocation. Radar uses RainViewer and OpenStreetMap; satellite imagery uses EUMETSAT/EUMETView or MET Norway. These services receive connection/IP data and the requested map region or image reference. Permissions are separate; revocation stops further requests but cannot retrieve information already sent to providers. Caches are local.

5. Network diagnosis and speed

The visible Network Detective runs periodic ICMP, DNS, route and, when applicable, TCP checks. Existing internet targets are 1.1.1.1 and 8.8.8.8; local DNS and router information supports diagnosis. Counterparties see connection information. The deliberately started native download test retrieves WOBCOM/Hetzner test files and may cause several hundred MB to over 1 GB of total traffic. The external M-Lab browser link is a separate action; starting a test and its privacy rules are handled on the provider site. Integrated M-Lab live operation remains blocked.

6. Updates and Windows features

MiniDesk checks its configured HTTPS version.json on GitHub Pages only after a click, without profile or device parameters. The host receives IP/connection data. No background check, automatic installation or unsolicited application-package transfer. WinGet and Windows Update separately communicate with Windows- or package-configured sources; their licence, account and privacy information remains applicable. Default-browser links open only after user action.

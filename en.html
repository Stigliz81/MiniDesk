Weather – now and ahead

More than a temperature.

Current weather readings, daily trends and forecasts come together in a clear view. Choose simple, extended or expert mode to suit the space on your desktop.

  • Temperature, feels-like temperature, wind, humidity, precipitation and other supplied readings. Unavailable values are not invented.
  • Morning, afternoon and evening: daily periods and a three-day preview with temperature ranges and rain probability.
  • Temperature chart for 7 or 14 days. The actual forecast range and completeness depend on the provider and available data.
  • Rain radar and satellite imagery extend expert mode. Regional coverage, image time and provider terms matter.
  • Choose a location yourself or enter coordinates. Forecasts, place search and imagery have separate voluntary permissions; without permission, that service is not queried.

Optional: radar & satellite

See clouds and rain in context.

Expert mode combines forecasts with map and image previews. RainViewer and OpenStreetMap support radar views; satellite images use EUMETSAT or MET Norway depending on the chosen region and service. Permissions and, where applicable, contact identification remain required.

A setup recommendation is not consent. Image access, coverage and availability are not guaranteed.

System monitoring & hardware

Know what is working inside.

System Status shows CPU, GPU and RAM usage. Hardware Overview adds technical details actually supplied by Windows.

  • Percentage values and bars for processor, graphics and memory. The GPU engine remains visible as a source indicator.
  • Temperatures appear only where the hardware and available sensor paths supply readings; no temperatures are invented.
  • Processor model, graphics card, memory, motherboard and BIOS/UEFI information in Hardware Overview.
  • Additional system, Windows and device information through the existing views. Missing details remain unavailable.

RAM test – start deliberately

Check memory. Understand the limits.

A short test and a timed intensive test write and compare data in a limited allocated memory region.

  • Short test with fixed and random patterns: 32 MiB by default, at most 64 MiB, depending on free memory.
  • Intensive test for 5, 10 or 20 minutes; at most 1 GiB and 20% of available physical RAM. At least 2 GiB stays free.
  • Progress, cycles and mismatches are displayed. Memory pressure or interruption stops the test safely; closing or collapsing the panel cancels it.
  • This is not a complete physical memory test or a guarantee that every RAM defect will be detected. A clean result applies only to the tested regions.

Response times, connection interruptions and history help you understand problems. Choose how often checks run; start a speed test separately.

Network Detective

Is the router or the internet the problem?

Continuous diagnosis distinguishes local reachability from the external connection. Latency, route and history help explain anomalies.

  • Router and internet checks with ping and latency readings, plus DNS, route, VPN and TCP information from the existing diagnostic paths.
  • Jitter describes changes between adjacent valid internet samples; packet loss is the share of failed samples. Blocked ICMP can limit the results.
  • History contains 24 real samples. Ping intervals of 5, 10, 30, 60 or 120 seconds can be selected and saved.
  • The visible gadget runs regular probes. Hiding it pauses its sampler; route changes or substantial interruptions clear the previous series.
  • Continuous network diagnosis measures reachability and latency. A speed test is a separate, deliberately started measurement that uses much more data.

Internet speed

A deliberate test, not a continuous download.

The native download test measures transfer speed using real test data. Progress, results, cancellation and errors stay visible.

  • It starts only when you press the button. A data usage notice appears in the dialog beforehand.
  • Total traffic can range from several hundred MB to over 1 GB. The internal limit on payload bytes read is not a fixed limit on all network traffic.
  • Consider mobile connections and data caps first. The external browser speed test is a separate explicit link, not an automatically started upload.

WinGet application updates

Update selectively. Follow the status.

MiniDesk uses WinGet to find available application updates and presents them in a clear table. You choose which offered applications to update.

  • Search for updates, inspect package names and versions, resize columns and read full names in tooltips.
  • Select applications using their checkboxes. Highlighting a row alone does not select an installation.
  • Start selected updates explicitly; confirmations, package licences and administrator prompts remain in place.
  • Follow progress and completion or error states. No unsolicited upgrade of every application and no promise of unattended installation.
  • WinGet updates applications. Windows Update is a separate entry point for Windows offerings; configured sources and Windows policies still apply.

The short route to Windows.

Frequently needed functions are accessible as labelled quick actions. The selection stays configurable; this overview does not enable optional actions.

Software & system

Windows Update and its options, Task Manager, startup apps and startup folder, Run, Disk Cleanup, Windows storage settings and clipboard history (Win+V).

Display, devices & audio

Display and scaling, Bluetooth, Device Manager, audio output, Volume Mixer and Sound (classic), with Playback, Recording, Sounds and Communications. Control your microphone and system audio directly.

Deliberate system actions

Rescan disks runs the existing confirmed rescan, not a new Disk Management tool. Turning off the display and administrative actions retain their prompts. Merely opening settings does not change devices.

Action Timer · Instant Actions · Power Plans

Plan the time. Choose the action.

Schedule sleep, restart, shutdown or lock for later, or use Instant Actions when you want to act now.

Before a scheduled shutdown starts, MiniDesk warns that open applications will be forcibly closed if necessary. Unsaved data may be lost. Cancel before handoff; no further MiniDesk confirmation appears when the timer expires. Instant Actions and other timer actions retain their existing behaviour.

  • Timed actions show remaining time and can be cancelled locally before handoff. Critical actions retain their minimum lead times and confirmations.
  • After Windows handoff, “Accepted · unconfirmed” is not proof of success. Resetting local status does not cancel a Windows request.
  • S3 requires appropriate system support. No hibernation/S4 function and no silent substitute on unsuitable devices.
  • Select existing Windows power plans using cards. No new plans are promised or created automatically; only offered plans are shown.
  • Test mode shows timer behaviour without real Windows actions. Save your work before real actions.

Drives & disk health

Distinguish space from health.

Storage space at a glance

Drives & Storage shows available drives, capacities, free and used space with clear bars. Unreachable locations remain identifiable.

Health information, where available

See available condition readings such as temperature, operating hours or wear. The information shown depends on the drive and Windows support.

No diagnostic guarantee

The overview replaces neither a full hardware diagnosis nor a backup. Missing readings do not confirm that a drive is healthy.

What happens when Management goes to the system tray?

“To system tray” hides Management while visible gadgets stay open. The existing instance can be shown again. “Quit MiniDesk” ends the application after confirmation.

How do network diagnosis and a speed test differ?

The visible Network Detective gadget checks reachability and latency. The separate speed test downloads large amounts of data after you start it to measure transfer speed.

Is weather consent required?

All consent is voluntary. Without the relevant permission, the corresponding online readings or images are unavailable. Recommended options are not enabled automatically.

Does MiniDesk update itself?

Update offers a manual version check using the configured official HTTPS address. Connection problems are reported clearly. No background checks or automatic installation.

Can I reset settings?

The explicit full reset offers an external backup by default. Back up your profile first and read the notices; it is not a Windows system cleanup.
